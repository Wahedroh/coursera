## ขั้นตอน wizard "ขึ้นปีการศึกษาใหม่"

1. สำรองข้อมูล (dispatch backup) + ดาวน์โหลด Excel ทั้งปี
2. เก็บปีเก่าถาวร (พิมพ์ "2569"): `classes.archived = 1, archived_on = วันนี้` · ปล่อยรหัส ZipGrade · ปิดการเข้าระบบนักเรียนเก่า (ยกเว้นนักเรียนทดสอบ) · ลบรูปงานนักเรียน (ไฟล์ R2 + `stored_files`)
3. เลือกเทอม 1/2570 + วันเปิดเทอม → `POST /api/teacher/terms { semester: 1, year }` (เมื่อทำ wizard แล้ว ให้ endpoint นี้รับเฉพาะเทอม 2 ในปีเดียวกัน)
4. นำเข้ารายชื่อจาก ZipGrade → สร้างห้องใหม่เสมอ (ไม่จับคู่ห้องที่เก็บถาวรแม้ชื่อซ้ำ — ปัจจุบัน `classes.name` เป็น unique ต้องจัดการ เช่น ใส่ปีต่อท้ายชื่อห้องเก่าตอนเก็บถาวร)
5. ย้ายนักเรียนทดสอบเข้าห้องใหม่
6. ลงตารางสอนใหม่ (ใช้ตั้งแต่วันเปิดเทอม) · ตั้งเป้าคาบ
7. ย้อนกลับ: ได้จนกว่าจะนำเข้ารายชื่อใหม่

เพิ่มหลังตกลง: `assignment_closed` (ครูบันทึกว่าไม่ส่งงาน — ผูกกับนักเรียน/งาน → เก็บถาวรไปกับห้อง)
- `leave_requests` (ใบลา — ผูกนักเรียน/ห้อง → เก็บถาวรไปกับห้อง · รูปแนบ `sub/<studentId>/…` ลบพร้อมรูปงานนักเรียน)
- `remedials` (งานซ่อม 0/ร/มส — ผูกนักเรียน/ห้อง → เก็บถาวร · ผลหลังซ่อมควรออกในเมนู "ปีที่ผ่านมา"/Excel · รูปแนบลบพร้อมรูปงาน)
- `makeup_exams` + `makeup_events` (สอบย้อนหลัง — ผูกรายการสอบ/นักเรียน → เก็บถาวรไปกับห้อง · รูปหลักฐาน `sub/<studentId>/…` ลบพร้อมรูปงาน)
- `exam_sets` (ชุดข้อสอบสอบย้อนหลัง — ของครู **คงไว้ข้ามปี** เหมือนคลังของครู · รูปหน้า `exam/…` และรูปโจทย์ `quiz/…` เก็บไว้)

- ตารางใหม่ที่ผูกกับห้อง/นักเรียน → ต้องถูกซ่อนเมื่อห้องเก็บถาวร และไม่ชนกับห้อง/รหัสใหม่
- ตารางใหม่ที่เป็นของครู → ตัดสินใจว่าคงไว้ข้ามปีหรือไม่ (ถามครูถ้าไม่ชัด)
- ไฟล์ใหม่ใน R2 ที่ผูกกับนักเรียน → พิจารณาลบตอนเก็บถาวรเหมือนรูปงาน
