# M3 บันทึกคะแนนสอบ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ครูสร้างรายการคะแนนสอบ (หลายห้องพร้อมกัน) กรอก/วางคะแนนจากกระดาษ เผยแพร่ และส่งออกสมุดคะแนนรวม; นักเรียนเห็นคะแนนที่เผยแพร่ของตัวเอง

**Architecture:** โดเมนใหม่ `src/server/scores/` (service + teacher-routes + student-routes) ตามแบบ assignments; ตาราง `score_items`, `scores` ใน D1; ฝั่ง client หน้า `TeacherScores` (รายการ + สร้าง), `TeacherScoreEntry` (ตารางกรอก), `StudentScores`; ฟังก์ชันล้วนตรวจ/แปลงคะแนนอยู่ใน `src/shared/scores.ts`

**Tech Stack:** Hono, Drizzle (D1), zod 4, React 19, write-excel-file, vitest + Playwright

**Spec:** `docs/superpowers/specs/2026-10-25-classroom-assistant-design.md` §4 (`score_items`, `scores`), §5.5, §8

## Global Constraints
- D1 ≤ 100 ตัวแปรต่อคำสั่ง: insert ทีละไม่เกิน 10 แถว, ห้าม `inArray` กับ list ยาว (กรองด้วย class join)
- คะแนน: 0 ≤ score ≤ max_score, ทศนิยมไม่เกิน 2 ตำแหน่ง; ค่าว่าง = ยังไม่กรอก (null)
- `published` ค่าเริ่มต้น false; นักเรียนเห็นเฉพาะรายการที่เผยแพร่ ของห้องตัวเอง และคะแนนของตัวเองเท่านั้น
- ไม่มี EXP จากคะแนนสอบ
- หมวด: `quiz`=สอบย่อย, `midterm`=กลางภาค, `final`=ปลายภาค, `other`=อื่น ๆ
- ข้อมูลทดสอบเป็นรายชื่อสมมติ

## Review Focus
1. วางคะแนนจาก Excel ที่มีบรรทัดว่าง/ช่องว่าง/`\r\n`/คอมมาทศนิยม → แปลงตามลำดับ ช่องว่าง = ไม่กรอก, ค่าผิดขึ้นกรอบแดงไม่บันทึก
2. ครูลดคะแนนเต็มหลังกรอกแล้วจนคะแนนเดิมเกิน → ปฏิเสธ 409 `scores_exceed_max`
3. นักเรียนข้ามห้อง/รายการยังไม่เผยแพร่/ยกเลิกเผยแพร่ → 404 และไม่โผล่ในรายการ
4. ติ๊ก "ขาดสอบ" แล้วมีคะแนนค้าง → absent ล้างคะแนนเป็น null
5. นักเรียนปิดใช้งาน/ห้องอื่น → บันทึกคะแนนไม่ได้ (404) และไม่อยู่ในตาราง

### Task 1: schema + shared validation
**Files:** `src/server/db/schema.ts`, `migrations/0003_*.sql` (drizzle-kit generate), `src/shared/scores.ts`, `tests/scores-shared.test.ts`
- `scoreItems` (id, classId→classes, title, category enum, maxScore real, takenOn text, published bool default false, sortOrder int default 0, createdAt, updatedAt)
- `scores` (id, itemId→scoreItems, studentId→students, score real nullable, absent bool default false, note text default '', updatedAt; unique(itemId, studentId))
- `scoreItemInputSchema` {title 1..200, category, maxScore >0 ≤1000 (2 ตำแหน่ง), takenOn = dateSchema}, `createScoreItemsSchema` (+classIds 1..50), `scoreInputSchema` {score number|null, absent bool, note ≤500}
- `parseScore(text: string, max: number): { ok: true; value: number | null } | { ok: false }` — trim, `,`→`.`, ว่าง → null, ต้องเป็นตัวเลข 0..max ทศนิยม ≤2
- `parsePastedColumn(text: string): string[]` — แยกบรรทัด (`\r?\n`), ตัด trailing newline สุดท้าย, เอาคอลัมน์แรกของแต่ละบรรทัด (แยก `\t`)
- `scoreStats(values: (number|null)[])` → {filled, avg, max, min} (null เมื่อไม่มีค่า)
- Tests: parseScore ('', ' 7.5 ', '7,25', '10.001', '-1', '11', 'abc'), parsePastedColumn ('8\r\n\r\n9.5\r\n' → ['8','','9.5']), scoreStats

### Task 2: teacher API
**Files:** `src/server/scores/service.ts`, `src/server/scores/teacher-routes.ts`, `src/server/index.ts`, `tests/scores-teacher.test.ts`
- POST `/api/teacher/score-items` {classIds,…} → `{ids}` (404 ถ้าห้องไม่มี)
- GET `/api/teacher/classes/:id/score-items` → รายการเรียงตาม takenOn, createdAt พร้อม `filled`, `total`
- GET `/api/teacher/score-items/:id` → `{ item, class, students: [{id, zipgradeId, title, firstName, lastName, score, absent, note}] }` (นักเรียน active ในห้อง เรียง sortOrder, zipgradeId)
- PUT `/api/teacher/score-items/:id` (แก้รายละเอียด; 409 `scores_exceed_max` ถ้ามีคะแนนเกิน max ใหม่)
- PUT `/api/teacher/score-items/:id/published` {published}
- DELETE `/api/teacher/score-items/:id` (ลบคะแนนในรายการด้วย, batch)
- PUT `/api/teacher/score-items/:id/scores/:studentId` {score, absent, note} → upsert; 400 `invalid_score`; absent ⇒ score null; 404 ถ้านักเรียนไม่อยู่ห้องนั้น/ไม่ active
- Tests: สร้าง 2 ห้อง, ตาราง, upsert/แก้ซ้ำ, เกิน max/ทศนิยม 3 ตำแหน่ง → 400, absent ล้างคะแนน, ข้ามห้อง 404, ลด max → 409, ลบ, นักเรียนเรียก 401
