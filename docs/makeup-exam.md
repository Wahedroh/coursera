# สอบย้อนหลังในระบบ — แผนที่ตกลงกับครูแล้ว

> ตกลงเมื่อ 22 พ.ย. 2569 · ยังไม่ได้ลงมือทำ

## กำหนดเวลาสอบย้อนหลัง (นับถอยหลัง)

- **ครูตั้งต่อรายการสอบ** (ค่าเริ่มต้น 14 วัน นับจากวันสอบจริง) — ตั้งตอนสร้าง/แก้รายการสอบ
- นักเรียนที่ขาดสอบเห็น **นับถอยหลัง** ในหน้าคะแนนสอบและหน้าแรก: "สอบย้อนหลังได้อีก 5 วัน 3 ชม." (ใกล้หมดเป็นสีแดง) + แจ้งเตือนก่อนหมด 3 วัน และ 1 วัน
- **หมดเวลาแล้วยังไม่ได้สอบ = ได้ 0 อัตโนมัติ** (ขาดสอบ → 0 · หมายเหตุ "หมดสิทธิ์สอบย้อนหลัง") — ทั้งคนที่ไม่ได้ขอ, ขอแล้วครูยังไม่อนุมัติ, และอนุมัติแล้วแต่ไม่ได้สอบ
- ช่วงเวลาสอบที่ครูอนุมัติต้องจบไม่เกินกำหนดนี้ · ถ้ากำลังสอบอยู่ตอนหมดกำหนด ให้ทำจนหมดเวลาทำของตัวเอง
- ครูขยายเวลาให้รายคนได้ (เช่น ป่วยยาว) · คืนสิทธิ์ได้ถ้าให้ 0 ไปแล้ว

## ลำดับการทำงาน

1. **นักเรียนขอ** — หน้าคะแนนสอบ: รายการที่ "ขาดสอบ" มีปุ่ม "ขอสอบย้อนหลัง" · ใส่เหตุผล + แนบหลักฐาน (รูป) · ขอได้จนกว่าจะหมดกำหนด (ดูด้านบน)
2. **ครูอนุมัติ** (แจ้งเตือนครู) — ตั้งค่าต่อคำขอ:
   - รูปแบบ: **ออนไลน์** หรือ **กระดาษ** (สอบต่อหน้าครู)
   - ช่วงเวลาที่เปิดให้สอบ + เวลาทำ (นาที)
   - ข้อสอบ: เลือกชุดข้อสอบ (ดูด้านล่าง) — ควรใช้ชุดที่ไม่ซ้ำกับวันสอบจริง
   - **เพดานคะแนน: ครูกำหนดตอนอนุมัติ** (ค่าเริ่มต้นตั้งได้ เช่น 80% · ป่วยมีใบรับรองให้ 100%)
   - รหัสเริ่มสอบ 6 หลัก (ระบบสร้าง · ครูบอกนักเรียนตอนนัด/ต่อหน้า)
3. **นักเรียนสอบออนไลน์** — กรอกรหัส → เริ่ม → **นักเรียนเลือกคำตอบ ระบบฝนให้** บนกระดาษคำตอบแบบ ZipGrade บนจอ → **หน้าตรวจทานคำตอบก่อนส่ง** (เห็นวงที่ฝนทุกข้อ · ข้อที่ยังไม่ตอบเป็นสีแดง) → ส่ง · หมดเวลาส่งเอง
4. **ครูตรวจ** — ระบบตรวจอัตโนมัติ + **สร้างกระดาษคำตอบ ZipGrade ที่ฝนแล้ว** (PDF · รหัสนักเรียนฝนให้ · พิมพ์แล้วสแกนด้วยแอป ZipGrade ได้) · ดูบันทึกการสอบ (เริ่ม/ออกจากหน้าจอ/ส่ง) · ใส่/แก้คะแนนเองได้ → บันทึกลงช่องสอบเดิมในสมุดคะแนน (หมายเหตุ "สอบย้อนหลัง") · ไม่ "ขาดสอบ" อีก
5. **แบบกระดาษ** — สอบต่อหน้าครู · ครูใส่คะแนนเองหรือนำเข้าจาก ZipGrade (ใช้หน้าคะแนนสอบเดิม) · คำขอปิดเป็น "สอบแล้ว"

## ข้อสอบออนไลน์ (ทั้งสองแบบ)

| แบบ | เตรียม | สลับข้อ/ตัวเลือกรายคน |
|---|---|---|
| **พิมพ์ในระบบ** (โจทย์ + ตัวเลือก + รูปประกอบ แบบชุดคำถามเกมการ์ด) | พิมพ์ทีละข้อ | ✅ ได้ |
| **PDF/รูปข้อสอบเดิม + เฉลย A–E** | อัป PDF + ใส่เฉลยทีละข้อ | ❌ ไม่ได้ (ลำดับตาม PDF) |

ทั้งสองแบบใช้กระดาษคำตอบบนจอแบบเดียวกัน · ตรวจที่เซิร์ฟเวอร์ · กระดาษ ZipGrade ที่สร้างให้ครูเรียงตามข้อของชุดต้นฉบับ (ไม่ใช่ลำดับที่สลับให้นักเรียน)

## ป้องกันทุจริต

มีแน่นอน:
- **เวลาฝั่งเซิร์ฟเวอร์** — เริ่มแล้วหยุดนับไม่ได้ · หมดเวลาส่งอัตโนมัติ · ทำได้ครั้งเดียว
- **เฉลยไม่ถึงเครื่องนักเรียน** — ตรวจที่เซิร์ฟเวอร์ · ไม่เห็นเฉลย/คะแนนจนครูบันทึก
- **เครื่องเดียว** — เริ่มที่เครื่องไหนสอบที่เครื่องนั้น · เปิดเครื่องอื่น = ธงแดงให้ครูเห็น

ครูเลือกแล้ว:
- **ตรวจการออกจากหน้าจอ** — สลับแอป/แท็บ/จอดับ บันทึกเวลาและระยะ · ครบ N ครั้งส่งทันที · **ลายน้ำชื่อ+รหัส+เวลา** ทุกหน้าข้อสอบ · ปิดคัดลอก/คลิกขวา/พิมพ์/เลือกข้อความ
- **รหัสเริ่มสอบจากครู** + เปิดเฉพาะช่วงเวลาที่อนุมัติ
- **สลับข้อ/ตัวเลือกรายคน** (ข้อสอบที่พิมพ์ในระบบ)

ไม่ทำตอนนี้: เซลฟีเริ่ม-จบ (เก็บรูปใบหน้านักเรียน)

## ข้อมูล (ร่าง)

- `exam_sets` ชุดข้อสอบ: ชื่อ · แบบ (typed/pdf) · คำถาม JSON หรือ fileKey + เฉลย[] · คะแนนต่อข้อ
- `makeup_requests` คำขอ: นักเรียน · score_item · เหตุผล · รูป · สถานะ (pending/approved/rejected/in_progress/submitted/graded/expired) · รูปแบบ · ช่วงเวลา · นาที · เพดาน% · รหัส (hash) · ชุดข้อสอบ · ลำดับข้อที่สลับ (seed) · deviceId · startedAt/submittedAt · คำตอบ[] · คะแนนอัตโนมัติ · คะแนนที่ครูบันทึก
- `makeup_events` บันทึกการสอบ: เวลา · ชนิด (start/blur/focus/device/submit/auto-submit) · ระยะเวลา
- ผูกกับนักเรียน/ห้อง → เก็บถาวรไปกับห้อง (ดู `docs/new-year-rollover.md`)

## คำถามที่ยังเปิดอยู่ (ตัดสินตอนลงมือ)

- ออกจากหน้าจอกี่ครั้งจึงส่งอัตโนมัติ (เสนอ 3 ครั้ง)
- ต้องการข้อสอบอัตนัยด้วยไหม (ตอนนี้ปรนัย A–E เท่านั้น)
